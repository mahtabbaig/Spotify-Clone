# 🎧 Spotify Clone 

A visually appealing **Spotify-inspired music player UI** built using pure **HTML and CSS**. This project focuses on replicating the modern layout and design aesthetics of Spotify while strengthening front-end fundamentals.

---

## 🚀 Project Overview

This project is a static front-end clone of Spotify designed to practice:

* Layout structuring
* Responsive design
* CSS styling and positioning
* UI/UX replication

It does **not include backend functionality or music streaming**, but it closely mimics the look and feel of the original platform.

---

## 🛠️ Built With

* **HTML5** – Structure of the web pages
* **CSS3** – Styling, layout, and responsiveness
* **Font Awesome** – Icons for UI elements

---

## ✨ Features

* 🎵 Clean and modern Spotify-like interface
* 📂 Sidebar navigation (Home, Search, Library)
* 🎧 Music cards with album covers
* ▶️ Playback control UI (Play, Pause, Next, etc.)
* ❤️ Like/Save icons
* 📱 Responsive layout (basic)

## 💡 What I Learned

* Structuring layouts using Flexbox/Grid

## ⚠️ Limitations

* No JavaScript functionality (no real music playback)
* Static UI only
* Limited responsiveness on all screen sizes
